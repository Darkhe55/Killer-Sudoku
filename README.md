# 杀手数独 Killer Sudoku

一个基于 Web 的杀手数独（Killer Sudoku）谜题游戏，原生 SVG 渲染，内置逻辑解题器。

## 在线体验

```bash
npm install
npm start
```

`npm start` 会等开发服务就绪后用默认浏览器打开 **http://127.0.0.1:5197/**。

> 也可以用 `npm run dev`，但不会自动打开浏览器。

## 游戏规则

- 在 N×N 格中填入 1..N，每行、每列、每个宫（4×4 为 2×2 宫、6×6 为 2×3 宫、9×9 为 3×3 宫、
  12×12 为 3×4 宫、16×16 为 4×4 宫）内不重复；识图导入题按图中粗线识别宫/区域，
  也支持**不规则宫（jigsaw）**，同样要求每个区域内 1..N 不重复
- 同一虚线笼内数字不能重复
- 笼内数字之和等于笼角标注的数字
- 题面预填数字不能修改

## 尺寸支持矩阵

| 尺寸 | 宫划分 | 内置题 | 笼和上限 | 渲染/校验/求解/逻辑回放 | 存档/旧题库 |
|------|--------|--------|----------|------------------------|-------------|
| 4×4 | 2×2 宫（4 宫） | ✅ 2 题 | 10 | ✅ | ✅ |
| 6×6 | 2×3 宫（6 宫） | ✅ 2 题 | 21 | ✅ | ✅ |
| 8×8 | 2×4 宫（8 宫） | —（可导入/生成） | 36 | ✅ | ✅ |
| 9×9 | 3×3 宫（9 宫） | ✅ 6 题（旧题库原样保留） | 45 | ✅ | ✅（旧存档直接续玩） |
| 10×10 | 2×5 宫 | —（可导入/生成） | 55 | ✅ | ✅ |
| 12×12 | 3×4 宫（12 宫） | —（生成耗时较长，暂未入内置题库） | 78 | ✅ | ✅ |
| 16×16 | 4×4 宫（16 宫） | —（生成耗时较长，暂未入内置题库） | 136 | ✅ | ✅ |

- 宫/区域：内置题为标准矩形宫（见上表）；识图导入题按图片粗线识别宫/区域，可为不规则宫（jigsaw），`regions` 字段逐格记录区域号，渲染/校验/求解同一套逻辑。
- 数值显示：1–9 显示为数字，10–16 显示为 A–G（编码用 36 进制，一格一个字符）。
- 编码：`givens|regions|cageOf:sums`；旧 9×9 题库的 givens/regions 是 `'0'..'9'`、笼号是 `0-9a-z`，
  新解码器同时接受大小写，旧题库/旧进度零迁移。
- 限制：
  - 只支持正方形题面，代码支持 4..16；内置题目前覆盖 4/6/9（12、16 的唯一解搜索较慢，可手动 `npm run gen` 扩展）。
  - 自定义题板关闭：虚线笼需要在题面里画出来并标注笼和，通用「填数字」编辑器无法表达。
  - 图片导入：已支持「粗宫线（可含不规则宫）+ 虚线笼 + 笼和」截图（如 `month.png`）；剩余限制见下文「从图片导入题库」。
  - 识别题目按图片中的宫线/区域线判定宫，内置题仍为标准矩形宫；同一条记录两种宫都可正常渲染/校验/求解。

## 数据存放

运行 `npm start` / `npm run dev` 时，题库、进度和上次题目保存在项目内 `data/` 目录；静态部署时自动降级到浏览器 localStorage。

## 功能

- **题库**：内置多道题，题目均校验唯一解
- **实时校验**：冲突与违规位置即时高亮，满足的条件同步变灰
- **逻辑解题**：规则引擎逐帧回放，显示每一步理由（基础规则 / 笼和 / 高级定式 / 反证 / 回溯分别标注）；回放中按钮变为停止，按 `P` 暂停/继续
- **提示一格 / 显示解**：提示优先揭示所有解一致的格子，显示解直接填入可行答案
- **撤销/重做**：按手势分组，一次拖拽只需一步撤销
- **进度保存**：自动保存当前题目进度，刷新不丢失
- **音效特效**：Web Audio 合成拨弦、水滴与落子动画，无外部音频资源
- **缩放/平移**：滚轮缩放，中键或 `Shift` 拖拽平移

## 逻辑定式

逻辑解题器按「候选集」推理，回放里每帧标注所用定式（规则 1–5）：

| 规则 | 定式 | 说明 |
|------|------|------|
| 1 | 唯一候选 | 行/列/宫/同笼已用数字排除后只剩一个候选 |
| 2 | 单元隐性唯一 + 笼 | 某数字在行/列/宫只剩一个位置；虚线笼内数字不重复且和等于标注（笼和组合表收窄） |
| 3 | 高级集合定式 | 45 法则 / innies-outies / 笼分割、宫-行/列交叉（pointing / claiming）、显性/隐性数对与三数组、X-Wing、Swordfish、XY-Wing |
| 4 | 反证 | 逐个试填，若立刻矛盾则该数字成立（带完整传播的兜底推理） |
| 5 | 回溯试探 | 规则 1–4 都不够时用回溯补完 |

- 45 法则：一行/列/宫的和恒为 N(N+1)/2，连续 k 行/列为其 k 倍；完全落在其中的笼和已知，剩余格的总和即可确定，再用「笼分割」把和分配回同一笼内的剩余格。
- 唯一矩形不适用于杀手数独：交换两个数字会让经过这些格的笼和变化，所以不启用。
- 规则 1–3 全部是「候选消除 / 落子」，每一步都能由集合条件证明，不针对具体题目硬编码。
- 反证与回溯保留为兜底：规则 4 会先做单格试填验证，规则 5 只在逻辑完全推不动时补完。
- `npm run audit` 会统计每题的基础 / 高级定式 / 反证 / 回溯帧数，可直接对比定式效果。

## 技术栈

- Vite + TypeScript
- 原生 SVG（无框架）
- Web Audio 合成音效（无外部资源）
- localStorage / 项目内 `data/` 存储进度与题库

## 项目结构

```
src/
  main.ts
  core/
    app.ts / ui.ts / view.ts      界面、交互、缩放、回放控制
    store.ts / library.ts         题库、进度、上次题目存储
    audio.ts / fx.ts              音效与落子特效
  game/
    adapter.ts                    游戏规则接入
    rules.ts                      规则引擎：行列宫 + 笼和 + 45 法则/高级定式
    logic.ts                      逻辑解题回放
    render.ts / state.ts          SVG 渲染与盘面状态
    validate.ts / solver.ts       实时校验与回溯求解
    puzzles.ts / puzzles-data.ts  题库加载与静态题库
```

## 从图片导入题库

```bash
npm run import-image -- board.png --verify                  # 预览识别结果并校验唯一解
npm run import-image -- board.png --append                  # 追加到识图题库（需唯一解）
npm run import-image -- board.png --dry --append            # 只预览不落盘
npm run import-image -- board.png --size 9                  # 指定网格尺寸（提示用）
npm run import-image -- board.png --map "3,4=5,5,1=7"       # 人工覆盖误识别的预填数字
npm run import-image -- board.png --sum "0,0=17,0,3=10"     # 人工覆盖误识别的笼和
npm run import-image -- board.png --regions standard        # 强制按标准矩形宫（默认 auto 按粗线识别）
npm run import-image -- board.png --json out.json --debug   # 导出识别 JSON / 打印中间统计
```

说明：

- Playwright + Edge 自动识图，流程：
  1. **网格线/尺寸**：按「贯穿全图的最长连续深色行程」找实线，在多组候选里选等距最长序列，
     自动判定 N 与格距（4..16），不受粗宫线、虚线、底纹干扰；
  2. **宫/区域**：逐条内部格线测量线宽，细线是普通格线、粗线是宫/区域边界；粗线围出的区域
     即可为**不规则宫（jigsaw）**，数量/尺寸与 N 不符时自动回退标准矩形宫并警告；
  3. **笼界**：虚线笼的虚线通常画在格线内侧（也可能画在格线中心），在格线两侧多条平行线上
     统计中等灰度覆盖率，落在虚线区间即判为笼界；
  4. **笼和/预填数字**：多字体模板字形识别，左上角字形拼成笼和，居中字形为预填数字。
- `--map` 覆盖预填数字、`--sum` 覆盖笼和，坐标 0 基（列,行）；`--map` 值大于 9 用 `A..G`，`--sum`
  写该笼左上格坐标。低置信度字形会在预览里给出「注意」。
- `--verify` 调项目 solver 校验唯一解并生成参考解；唯一性检查**超时只警告**（不中断）。
- `--append` 追加到 `src/game/imported-puzzles.ts`（不会覆盖内置题，`npm run gen` 也不会动它）；
  确认唯一解才写入，超时未确认时会警告并以空参考解写入，`--dry` 时绝不落盘。
- 已知限制：
  - 笼界只识别虚线风格；若题图用「实线粗笼」而粗线又被当作宫线，笼界可能识别不出（会警告）；
  - 区域形状只做自动识别，不支持逐格手工改区域（可用 `--regions standard` 回退标准宫）；
  - 字形识别依赖清晰截图；字体/分辨率特殊、笼和与预填混淆时会给出低置信度警告，可用 `--map/--sum` 修正；
  - 只支持正方形题面（4..16），任意尺寸的内置/导入题都可正常游玩。

> `month.png`（9×9，不规则宫 + 36 个虚线笼、纯笼和题）已可用默认参数识别：
> `npm run import-image -- month.png --verify` 得到 9 个 9 格不规则区域、36 个笼、唯一解。
